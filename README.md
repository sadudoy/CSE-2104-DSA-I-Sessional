# CSE 2104 - Data Structures and Algorithms I (Sessional)

This repository contains implementations and practice code for the course **CSE 2104: Data Structures and Algorithms I Sessional**. The codes are written in C++ as part of academic coursework and self-practice.

---

## Course Overview

This course focuses on the implementation and understanding of fundamental data structures and algorithms, including:

- Arrays (static and dynamic operations)
- Strings and basic string manipulation
- Searching algorithms (Linear Search, Binary Search)
- Sorting algorithms (Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort)
- Linked Lists (Singly, Doubly, Circular)
- Stack implementation
- Queue implementation (Linear and Circular)
